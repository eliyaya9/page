# תצוגה מקדימה לדף הקורס

אם לא מצליח להיפתח לך הדף בלחיצה כפולה על הקובץ, הדרך הכי יציבה היא להריץ שרת מקומי:

```bash
cd /workspace/page
./preview.sh
```

לאחר ההרצה, פתח בדפדפן:

- http://127.0.0.1:4173
- או http://localhost:4173

## אם עדיין לא נפתח

1. ודא שהפקודה `./preview.sh` נשארת רצה (לא לסגור את הטרמינל).
2. נסה פורט אחר:

```bash
PORT=8080 ./preview.sh
```

ואז פתח: `http://127.0.0.1:8080`.

3. אם אתה עובד דרך שרת מרוחק/קונטיינר – צריך לעשות Port Forward לפורט שבחרת (למשל 4173).

## עצירה

בטרמינל שמריץ את השרת לחץ `Ctrl+C`.
